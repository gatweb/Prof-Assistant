Variables & Types CH2

Les variables permettent de stocker temporairement des données en mémoire. En JavaScript moderne, nous utilisons principalement deux mots-clés pour déclarer des variables :

javascript
const nom = "Alex";   // valeur fixe — à utiliser par défaut
let score = 0;        // valeur modifiable — si réassignation
// var → legacy (ancienne syntaxe), à éviter absolument

Voici la liste des types de données primitifs abordés dans le cadre de l'UAA5 :

Type Exemple Résultat de typeof Description
number 42, 3.14, -5 "number" Valeurs numériques (entières ou décimales).
string "Bonjour", 'JS' "string" Chaînes de caractères (du texte).
boolean true, false "boolean" Valeurs logiques (vrai ou faux).
undefined let x; "undefined" Variable créée mais à laquelle aucune valeur n'a été assignée.
null const v = null; "object" ← bug historique ! Représente l'absence intentionnelle de valeur.
💡
Règle de bonne pratique
Déclarez par défaut toutes vos variables avec const. Utilisez let uniquement si vous devez explicitement réassigner une nouvelle valeur à cette variable plus tard.
⚠️
Le piège de typeof null
L'instruction typeof null renvoie "object". C'est un bug historique du langage JavaScript qui n'a jamais été corrigé pour des raisons de rétrocompatibilité. Pour vérifier si une variable vaut null, faites directement un test d'égalité stricte : variable === null.

Opérateurs CH2

Arithmétiques

Utilisés pour réaliser des calculs mathématiques standard :

Op. Opération Exemple Résultat Essayer
+ Addition 10 + 3 13
- Soustraction 10 - 3 7
* Multiplication 10 * 3 30
/ Division 10 / 3 3.33…
% Modulo (reste) 10 % 3 1
** Exponentiation (puissance) 2 ** 8 256

Comparaison

Permettent de tester des relations logiques entre des valeurs :

Op. Signification Exemple Résultat Essayer
=== Strictement égal (valeur et type) 5 === "5" false
== Égal (faible, fait des conversions) 5 == "5" true
!== Strictement différent 5 !== "5" true
< / > Strictement inférieur / supérieur 3 < 5 true
<= / >= Inférieur ou égal / supérieur ou égal 5 <= 5 true

Logiques

Pour combiner plusieurs conditions :

Op. Signification Exemple Résultat Essayer
&& ET — les deux conditions doivent être vraies true && false false
|| OU — au moins une condition doit être vraie false || true true

Raccourcis d'affectation

javascript
score += 10;   // Équivaut à : score = score + 10
score -= 5;    // Équivaut à : score = score - 5
score *= 2;    // Équivaut à : score = score * 2
score++;       // Équivaut à : score = score + 1 (Incrémentation)
score--;       // Équivaut à : score = score - 1 (Décrémentation)
💡
Règle de comparaison recommandée
Utilisez toujours l'égalité stricte === et l'inégalité stricte !==. N'utilisez jamais == ni != car ils effectuent des coercions de type implicites confuses qui créent des bugs insidieux.
⚠️
Le piège de la coercion avec l'addition
L'opérateur + fait de la concaténation si l'un des deux éléments est du texte : "5" + 3 donne "53". Les autres opérateurs arithmétiques forcent la conversion numérique : "5" - 3 donne le nombre 2.

Chaînes de caractères CH4

Les chaînes de caractères permettent de manipuler du texte. On peut les déclarer de trois façons différentes :

javascript
const a = "guillemets doubles";
const b = 'guillemets simples';
const c = `template literal — ${a}`;       // expression dans ${ }
const d = `Niveau ${score * 2}`;           // accepte n'importe quel calcul JS

Les chaînes possèdent des propriétés (comme .length) et de nombreuses méthodes prédéfinies :

Méthode / Propriété Description Exemple → Résultat
.length Renvoie la longueur du texte (nombre de caractères). "Bonjour".length → 7
[i] / .charAt(i) Lit le caractère à l'indice i (commence à 0). "abc"[0] → "a"
.toUpperCase() Convertit le texte tout en majuscules. "js".toUpperCase() → "JS"
.toLowerCase() Convertit le texte tout en minuscules. "JS".toLowerCase() → "js"
.trim() Supprime les espaces inutiles au début et à la fin. " hi ".trim() → "hi"
.includes(sub) Vérifie si le texte contient la sous-chaîne sub. "hello".includes("ell") → true
.startsWith(sub) Vérifie si le texte commence par sub. "hello".startsWith("he") → true
.endsWith(sub) Vérifie si le texte se termine par sub. "hello".endsWith("lo") → true
.indexOf(sub) Renvoie la position de la sous-chaîne, ou -1 si absente. "hello".indexOf("l") → 2
.slice(d, f) Extrait une partie du texte depuis l'indice d jusqu'à f exclu. "hello".slice(1, 3) → "el"
.replace(x, y) Remplace la première occurrence de x par y. "aa".replace("a", "b") → "ba"
.replaceAll(x, y) Remplace toutes les occurrences de x par y. "aa".replaceAll("a", "b") → "bb"
.split(sep) Découpe la chaîne selon le séparateur pour en faire un tableau. "a,b".split(",") → ["a", "b"]
.repeat(n) Répète la chaîne n fois. "ab".repeat(3) → "ababab"
⚠️
Les chaînes sont immuables
En JavaScript, les chaînes de caractères ne peuvent pas être modifiées directement en mémoire. Les méthodes comme .toUpperCase() ou .trim() ne modifient pas la variable de départ, elles renvoient une nouvelle chaîne. Vous devez donc réassigner ou stocker le résultat :
const monTexteMaj = monTexte.toUpperCase();

Entrées / Sorties & DOM CH3+

JavaScript permet de communiquer avec l'utilisateur (Entrées/Sorties) soit via des boîtes de dialogue système, soit en manipulant directement les éléments du document HTML (le DOM).

javascript
// --- 1. ENTRÉE UTILISATEUR VIA PROMPT ---
const saisie = prompt("Ton prénom ?");
// → Renvoie une string ou null si l'utilisateur clique sur "Annuler"
const n = Number(saisie); // Toujours convertir avant d'effectuer un calcul numérique !

// --- 2. LIRE UN CHAMP DE SAISIE DANS LA PAGE HTML ---
const val = document.getElementById("monInput").value;  // Toujours du texte (string) !
const nb  = Number(document.getElementById("monInput").value);

// --- 3. MODIFIER LA PAGE HTML ---
element.textContent = "texte brut";         // Remplace le texte brut (sécurisé)
element.innerHTML   = "<b>texte gras</b>";  // Interprète les balises HTML
element.className   = "card card-ok";       // Écrase et remplace les classes CSS
element.disabled    = true;                 // Active ou désactive un bouton
output.innerHTML    = "";                   // Vide entièrement le contenu d'une boîte

// --- 4. CRÉER ET INSÉRER UN NOUVEL ÉLÉMENT ---
const div = document.createElement("div");
div.className   = "card";
div.textContent = "Contenu dynamique";
document.getElementById("output").appendChild(div);

// --- 5. ÉCOUTER UN ÉVÉNEMENT (CLIC...) ---
document.getElementById("btn").addEventListener("click", function() {
    const valeurSaisie = document.getElementById("input").value;
    // Traitement exécuté au moment du clic...
});

// --- 6. ÉTAT PERSISTANT ENTRE LES CLICS ---
let compteur = 0;   // Déclarée en dehors du listener : sa valeur survit aux clics
document.getElementById("btn").addEventListener("click", function() {
    compteur++;      // Incrémente la variable globale à chaque clic
});

Conditions CH5

Les structures conditionnelles permettent de dériver le comportement d'un programme en fonction de critères logiques.

Structure IF / ELSE IF / ELSE

javascript
if (score >= 85) {
    // Exécuté si la condition est vraie. Les blocs suivants sont alors ignorés.
} else if (score >= 70) {
    // Testé uniquement si la première condition était fausse (false).
} else {
    // Exécuté si aucun des tests précédents n'était vrai (fallback).
}

Structure SWITCH (Valeurs discrètes précises)

javascript
switch (choix) {
    case "1":
        // Traitement pour le choix "1"
        break;    // OBLIGATOIRE — empêche de continuer vers les cases suivants !
    case "2":
        // Traitement pour le choix "2"
        break;
    default:
        // Exécuté si aucune valeur case ne correspond
}

L'opérateur Ternaire

javascript
const statut = hp > 0 ? "Vivant" : "KO";
//            [condition] ? [si vrai] : [si faux]

Valeurs considérées comme Falsy (évaluées à false dans un test logique) :
false, 0, "" (chaîne vide), null, undefined, NaN.

💡
Ordre logique des Else If
Placez toujours vos conditions de la plus restrictive à la plus générale. Si vous écrivez if (score > 50) en premier puis else if (score > 90), le second bloc ne s'exécutera jamais car un score de 95 validera le premier test et arrêtera l'évaluation.
⚠️
Comparaison stricte du Switch
Le bloc switch réalise une comparaison en égalité stricte (===). Puisque l'instruction prompt() renvoie par défaut du texte, vous devez tester des chaînes de caractères : écrire case "1": (avec guillemets) et non case 1:.

Boucles CH6-7

Les boucles (ou structures répétitives) permettent de répéter un bloc d'instructions un certain nombre de fois.

javascript
// --- 1. BOUCLE WHILE (Nombre d'itérations inconnu à l'avance) ---
let energie = 100;
while (energie > 0) {
    energie -= 25;   // IMPORTANT : faire évoluer la variable pour éviter une boucle infinie !
}

// --- 2. BOUCLE FOR (Nombre d'itérations connu à l'avance) ---
for (let i = 0; i < 10; i++) {
    // S'exécute pour i allant de 0 à 9 (10 itérations au total)
}

// --- 3. PARCOURIR LES CARACTÈRES D'UNE CHAÎNE (String) ---
for (let i = 0; i < str.length; i++) {
    const caractere = str[i]; // ou str.charAt(i)
}

// --- 4. BOUCLE DO...WHILE (S'exécute toujours au moins une fois) ---
do {
    // Code exécuté une fois avant d'évaluer la condition du while en bas
} while (condition);

// --- 5. INSTRUCTIONS DE CONTRÔLE D'ÉCHAPPEMENT ---
for (let i = 0; i < 100; i++) {
    if (i === 5) break;         // Sort immédiatement de la boucle
    if (i % 2 === 0) continue;  // Saute le reste du code et passe à l'itération suivante (impairs uniquement)
}
Boucle À utiliser quand...
for Le nombre d'itérations est connu à l'avance (ex: 10 itérations, longueur d'un texte, etc.).
while Le nombre d'itérations est imprévisible et dépend d'une condition (ex: jusqu'à ce que l'utilisateur tape une bonne réponse).
do...while Identique à la boucle while, mais le code doit s'exécuter au moins une fois avant de tester la condition.

Pattern pour générer un entier aléatoire

Pour générer un nombre entier aléatoire compris entre min et max (inclus) :

javascript
Math.floor(Math.random() * (max - min + 1)) + min

// --- Exemples concrets ---
Math.floor(Math.random() * 6)  + 1;   // Dé de 6 faces → renvoie un nombre entier entre 1 et 6
Math.floor(Math.random() * 100) + 1;  // Nombre mystère → renvoie un nombre entier entre 1 et 100

Patterns algorithmiques CH7

Les patterns algorithmiques de référence sont des structures types à connaître par cœur pour résoudre les problèmes d'examens (SEGEC) :

javascript
// --- 1. FILTRAGE (Traiter seulement certains éléments) ---
for (let i = 0; i < n; i++) {
    if (condition) { 
        /* Code de traitement de l'élément i */ 
    }
}

// --- 2. ACCUMULATION CONDITIONNELLE (Somme ou décompte) ---
let somme = 0;
let nombreElements = 0;
for (let i = 0; i < n; i++) {
    if (condition) { 
        somme += valeur; 
        nombreElements++; 
    }
}

// --- 3. RECHERCHE DE MAXIMUM / MINIMUM (Initialiser à null !) ---
let min = null;
let max = null;
for (let i = 0; i < n; i++) {
    if (min === null || valeur < min) {
        min = valeur;
    }
    if (max === null || valeur > max) {
        max = valeur;
    }
}

// --- 4. RECHERCHE AVEC ARRÊT ANTICIPÉ (Drapeau 'found') ---
let found = false;
let indexTrouve = -1;
for (let i = 0; i < n; i++) {
    if (condition) { 
        found = true; 
        indexTrouve = i; 
        break; // Interrompt immédiatement l'exécution de la boucle !
    }
}
⚠️
L'initialisation critique du Min / Max
N'initialisez jamais vos variables min ou max à 0 par défaut. Si votre liste contient uniquement des notes positives (ex: 12, 15, 8) et que vous avez initialisé min = 0, votre programme affichera à la fin que le minimum est 0 (ce qui est faux car 0 n'était pas dans la liste). Initialisez toujours à null.

Validation — Le pattern de référence CH3,5

Pour écrire du code robuste, vous devez valider systématiquement toute entrée fournie par l'utilisateur (via un prompt() ou un formulaire HTML) avant d'effectuer le moindre traitement logique ou calcul.

javascript
// --- 1. PATTERN DE VALIDATION D'UNE SAISIE TEXTE ---
const saisie = prompt("Ton prénom ?");
if (saisie === null) { 
    afficherErreur("Saisie annulée par l'utilisateur."); 
    return; // Arrêt immédiat
}
if (saisie.trim() === "") { 
    afficherErreur("Le champ ne peut pas être vide."); 
    return; // Arrêt immédiat
}
const prenom = saisie.trim(); // Saisie nettoyée et garantie valide !

// --- 2. PATTERN COMPLET DE VALIDATION D'UNE SAISIE NUMÉRIQUE ---
const saisieNb = prompt("Entrez un nombre (0-100) :");
if (saisieNb === null) { 
    afficherErreur("Saisie annulée."); 
    return; 
}
const n = Number(saisieNb);
if (isNaN(n)) { 
    afficherErreur("Erreur : ce n'est pas un nombre valide."); 
    return; 
}
if (n < 0 || n > 100) { 
    afficherErreur("Erreur : le nombre doit être compris entre 0 et 100."); 
    return; 
}
// Ici, la variable 'n' est garantie être un nombre valide entre 0 et 100
💡
Ordre obligatoire des vérifications
Vous devez obligatoirement suivre cet ordre de test :
1. Tester la valeur null (bouton Annuler).
2. Tester si la chaîne est vide (trim() === "").
3. Tester la validité du format (isNaN après conversion).
4. Tester les limites logiques (plage de valeurs).
Si vous tentez d'appeler saisie.trim() sans tester saisie === null d'abord, votre programme va crasher avec l'erreur TypeError: Cannot read properties of null (reading 'trim').

Les 10 pièges les plus fréquents Tous

Voici un récapitulatif synthétique des erreurs de codage les plus courantes à éviter lors des épreuves pratiques :

Piège classique Conséquence dans le script Correction à appliquer
Utiliser == "5" == 5 donne true (coercion implicite dangereuse). Utiliser systématiquement === (égalité stricte).
Saisie brute prompt() Effectue des calculs de texte au lieu de nombres. Convertir avec Number(saisie) avant tout calcul.
L'addition "5" + 3 Affiche "53" (concaténation de texte). Convertir d'abord ou utiliser la soustraction (qui force le calcul).
Initialiser min = 0 Si toutes vos notes sont positives, min restera faussement bloqué à 0. Initialiser la recherche à null.
Switch : case 1: Le case n'est jamais activé car prompt() renvoie du texte (type string). Écrire les valeurs entre guillemets : case "1":.
Oubli de break Fall-through : le script exécute les blocs case suivants par erreur. Placer un break; à la fin de chaque bloc case.
Tester typeof null Renvoie "object" au lieu de "null" (bug du langage). Faire directement un test d'égalité stricte : === null.
getMonth() de Date Janvier renvoie 0, Décembre renvoie 11. Créer un tableau de textes ["Janvier", ...] et lire à l'index.
getDay() de Date Dimanche renvoie 0, Lundi renvoie 1. Créer un tableau de textes ["Dimanche", ...] et lire à l'index.
Modifier string sans assigner Le résultat de texte.toUpperCase() est perdu en mémoire. Réassigner la valeur : const maj = texte.toUpperCase();

Résumé de la coercion automatique

javascript
"5" + 3;       // → "53"  (Le signe + avec du texte force la concaténation)
"5" - 3;       // → 2     (La soustraction force la conversion numérique)
"abc" * 2;     // → NaN   (Conversion impossible car le texte n'est pas numérique)
true + 1;      // → 2     (Le booléen true est converti en nombre 1)
false + 5;     // → 5     (Le booléen false est converti en nombre 0)
null + 5;      // → 5     (null est converti en nombre 0)
undefined + 5; // → NaN   (undefined ne peut pas être converti en nombre valide)
