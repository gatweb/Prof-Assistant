# Prof Assistant - Firebase Functions

🚀 **Prof Assistant** est une plateforme éducative innovante conçue pour simplifier et enrichir l'expérience des professeurs et des élèves grâce à l'Intelligence Artificielle.

## 🎯 Objectif du Projet
L'application offre une interface simple et intuitive avec deux rôles principaux :
- **Pour les professeurs :** Un assistant IA dédié à la pré-correction des copies et au suivi des élèves.
- **Pour les élèves :** Un assistant pédagogique interactif pour les guider pas à pas dans leurs apprentissages.

Le système gère des **exercices en direct** et sera bientôt enrichi d'un module complet de **gestion de cours**.

## 🛠 Stack Technique
- **Backend / Serveur :** Node.js
- **Infrastructure :** Firebase (Cloud Functions)

## 🚀 Démarrage Rapide

1. Assurez-vous d'avoir installé les outils Firebase CLI :
   ```bash
   npm install -g firebase-tools
   ```
2. Installez les dépendances locales :
   ```bash
   npm install
   ```
3. Démarrez l'émulateur local ou déployez :
   ```bash
   npm run serve # (ou firebase emulators:start)
   ```
